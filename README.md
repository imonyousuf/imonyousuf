## What I've built

**PathPro AI** · [App Store](https://apps.apple.com/us/app/pathpro-ai-career-coach/id6756760577) · [Site](https://www.pathproai.app/)
An iOS career coach, live on the App Store. It matches people to careers with a score and the reasons, then
guides them through a four-week plan. React Native, Expo, TypeScript, Supabase, OpenAI API.

**Loonie** · [Code](https://github.com/imonyousuf/loonie) · [Live](https://loonie-by-imon.vercel.app)
A full-stack paycheque budgeting app. It splits each paycheque into bills, essentials, people owed and an
emergency fund, and reads bank statements in the browser. React 19, TypeScript, Convex, 80 tests.

**Loadout** · [Code](https://github.com/imonyousuf/loadout) · [Live](https://loadout-by-imon.vercel.app)
Turns a store order into stable pallets and shows the build in 3D. It came from building pallets by hand at
work. TypeScript, three.js, React Three Fiber, 22 tests.

**Show Stoppers by Punom** · [Site](https://showstoppersbypunom.com)
An e-commerce site for a jewellery shop, with an admin app the owner runs from a phone. Client work.
Next.js, React, TypeScript, Supabase, Tailwind CSS.

**Hueshot** · [Code](https://github.com/imonyousuf/hueshot) · [Live](https://hueshot.vercel.app)
Pulls a colour palette out of a photo and exports CSS variables, Tailwind and JSON tokens.
TypeScript, Vite, Canvas, Web Workers, 32 tests.

**Kinetype** · [Code](https://github.com/imonyousuf/kinetype) · [Live](https://kinetype-by-imon.vercel.app)
Animates a line of text in six motion styles and exports video from the browser.
TypeScript, Canvas, MediaRecorder, 13 tests.

**Mote** · [Code](https://github.com/imonyousuf/mote) · [Live](https://mote-by-imon.vercel.app)
Turns a logo into interactive particles, with MP4 export and a 13 KB embed script.
TypeScript, Canvas, GSAP, 33 tests.

PathPro AI and Show Stoppers are a live product and a client's shop, so their code is private.
